# Reference — Administration

Back-office endpoints **of one classroom**. Every route hangs off `/api/v1`. **Auth**: `admin` = `tenant_admin` or `super_admin` with a Bearer JWT, always over the token's tenant; some blocks require a strict `super_admin`; those marked <span class="didacta-chip didacta-chip--ee">EE</span> additionally require an Enterprise capability (without a license → **402**).

!!! note "What operates the whole installation, on another page"
    The list of organizations (`/admin/tenants`), the provisioning credential, support access, the subscription gate, the license (`/admin/license`), the instance settings and the opt-in registration are in [Instance and control plane](instance-operations.md).

## Users — `/admin/users` (admin, scoped to the token's tenant)

| Method | Route | What it does |
|---|---|---|
| GET | `/admin/users` | Paginated list with filters (`search`, `status`, `role`, `externalSource`, `page`, `limit` —default 100, max 500—). |
| GET | `/admin/users/:id` | Detail with roles and recent sessions. |
| POST | `/admin/users` | Invites: creates a `PENDING` user + an email to set a password. `{ email, name?, role, accessGroupId? }`. |
| POST | `/admin/users/bulk-invite` | Bulk upload (CSV): `{ rows: [{ email, name? }] (1–300), role, accessGroupId? }`, with the same role and group for the whole batch. Answers before finishing; progress is queried separately. |
| GET | `/admin/users/bulk-invite/status` | Progress of the bulk upload in progress (or the last one finished). |
| PATCH | `/admin/users/:id/status` | `ACTIVE`/`SUSPENDED`/`DEACTIVATED` (suspending invalidates sessions; you cannot suspend yourself). |
| POST · PATCH | `/admin/users/:id/roles` · `/roles/remove` | Assigns / removes a role. Assignable: `tenant_admin`, `formador`, `alumno`, `auditor`, `inspector` (read-only Fundae follow-up), `empresa_manager` (never `super_admin`). |
| POST | `/admin/users/:id/resend-invite` | Resends the invitation. |

With sign-ups frozen by the control plane, single invitation and bulk upload answer **409 `TENANT_SIGNUPS_FROZEN`**.

## Classroom — `/admin/tenant-settings/academy` (admin)

| Method | Route | What it does |
|---|---|---|
| GET | `/admin/tenant-settings/academy` | Name, identifier (`slug`, not editable here), primary address, language (`locale`: `es`/`en`/`pt`, with `localeSource`: `setting`, `simple-mode`, `admin` or `default`) and whether the public page is on (`publicHome`). `looksAutogenerated` warns that the name is still the one deduced at purchase. |
| PUT | `/admin/tenant-settings/academy` | Changes `name`, `locale` and/or `publicHome` (at least one), always over your **own** classroom. `publicHome: false` sends people arriving without a session straight to sign-in instead of the home page. |

## Academy address — `/admin/tenant-settings/academy/address` (admin)

"Your academy's address": whoever administers the classroom changes its subdomain on their own (`<x>.<suffix>` → `<y>.<suffix>`), always over their **own** classroom. It only exists if the instance defines `TENANT_SUBDOMAIN_SUFFIX`; without it, the three routes answer **404** `ACADEMY_ADDRESS_DISABLED`. See [Branding → Academy address](../../configuration/branding.md#academy-address-subdomain).

| Method | Route | What it does |
|---|---|---|
| GET | `/admin/tenant-settings/academy/address` | Current address (`hostname`, `label`), the fixed part (`suffix`) and whether it can be changed now: `canChange`, `blockedReason` (`no_address` \| `own_domain` \| `limit`), `changesLeft` out of `maxChanges` (3) every `windowDays` (30) and `nextChangeAt` once they are used up. |
| GET | `/admin/tenant-settings/academy/address/availability?label=` | Is it free? `{ label, hostname, status }`, with `status`: `available` \| `current` \| `invalid` \| `reserved` \| `taken`. It never says which classroom has it. |
| PUT | `/admin/tenant-settings/academy/address` | `{ label }` → `{ previousHostname, hostname, state }`. The new one becomes primary; the previous one still belongs to the classroom, its pages redirect (308) to the new one and its `/api/*` keeps answering. Sessions do not carry over from one address to the other. |

**Errors**: `ACADEMY_ADDRESS_DISABLED` 404 · `ACADEMY_ADDRESS_FORBIDDEN` 403 · `ACADEMY_ADDRESS_INVALID` / `ACADEMY_ADDRESS_RESERVED` / `ACADEMY_ADDRESS_UNCHANGED` 400 · `ACADEMY_ADDRESS_TAKEN` / `ACADEMY_ADDRESS_CHANGE_LIMIT` / `ACADEMY_ADDRESS_OWN_DOMAIN` / `ACADEMY_ADDRESS_NONE` 409.

## Simple mode — `/admin/simple-mode` (admin)

Simple mode folds away the panel's advanced parts and guides setup in three questions. Nothing is deleted when you turn it off.

| Method | Route | What it does |
|---|---|---|
| GET · PUT | `/admin/simple-mode` | Is the classroom in simple mode? · turn it on or off (`{ enabled }`). |
| GET | `/admin/simple-mode/currencies` | Currencies the classroom can set a price in. |
| POST | `/admin/simple-mode/quick-start` | **3-question setup**: `{ academyName, offer: course \| membership, title?, amountCents, currency, locale? }`. Creates the course or plan as a draft, the basic spaces and a welcome post. Idempotent. |
| GET | `/admin/simple-mode/start-here` | State of the 6 "Start here" steps and a summary after selling. |
| PUT | `/admin/simple-mode/price` | Changes the offer's price (`{ amountCents, currency }`) and the sale price if already published. |
| GET · PUT | `/admin/simple-mode/courses/:courseId/sale` · `/price` | A course's price and sale for its editor (the offer's, that of the membership that includes it, or that of its own purchase option) · changes the price from the course editor: the same change as the "Price" step. |
| POST | `/admin/simple-mode/academy/confirm` | Marks "Your academy" as reviewed even if logo and color do not change. |
| POST | `/admin/simple-mode/adopt` | A classroom with courses, students or sales moves to simple mode as it is, with no setup from scratch. |
| POST | `/admin/simple-mode/publish` | Publishes the offer and puts it on sale at the saved price; returns the sales-link path. |

Domain errors (`code`): `SIMPLE_MODE_PAYMENTS_NOT_READY`, `SIMPLE_MODE_NO_LESSONS`, `SIMPLE_MODE_NO_PRICE`, `SIMPLE_MODE_NO_OFFER` and `SIMPLE_MODE_COURSE_NOT_FOR_SALE` → **409**; `SIMPLE_MODE_COURSE_NOT_FOUND` → 404; the remaining validations, 400.

## Modules — `/admin/modules`

| Method | Route | Auth | What it does |
|---|---|---|---|
| GET | `/admin/modules` | admin | Available modules with state and dependencies (`?tenantId=` for another tenant, super_admin only). |
| POST | `/admin/modules/:name/enable` · `disable` | admin | Enables (idempotent) · disables (`?force=true` cascades). Errors: 409 active dependents, 422 core module. |
| POST | `/admin/modules/install` | super_admin | Installs a signed ZIP package (body = raw ZIP, `Content-Type: application/zip`). Typed errors: 413 too large, 422 signature/lint/boot, 403 untrusted vendor, 412 incompatible core, 409 reserved or already-installed name. |
| GET | `/admin/modules/installed[/:name[/routes]]` | super_admin | Installed third-party modules · detail · exposed routes. |
| DELETE | `/admin/modules/installed/:name` | super_admin | Uninstalls (unregisters routes, deletes record and blob) → 204. |

The `mod.payouts` module (platform payouts) only appears in the list when the operator turns the platform mode on (**Cloud**).

## Sales — `/admin/sales` (admin)

The classroom's sales ledger: one-off payments and collected installments. Only `tenant_admin` and `super_admin` (`SALES_ADMIN_ROLE_REQUIRED`).

| Method | Route | What it does |
|---|---|---|
| GET | `/admin/sales` | Sales with buyer, product, coupon or referral, commissions, net, status and country. Filters: `from` (included) and `to` (excluded) in ISO, `product` (`course:<uuid>` or `plan:<uuid>`), `status` (`paid`, `held`, `transferred`, `refunded`, `disputed`), `q` (name, email or product), `page` and `pageSize` (max 100). Returns `{ items, page, pageSize, total, totals, products, platform }`; totals are **per currency**. |
| GET | `/admin/sales/export` | Exports the filtered sales as CSV (UTF-8 with BOM) or Excel, in the classroom's language: `format=csv\|xlsx`, `view=sales` (one row per sale) or `buyers` (one per buyer and currency). Max 50,000 rows. Recorded in the audit log (`sales.exported`); a support session cannot export (403). |
| GET | `/admin/sales/:id` | One sale (`order:<uuid>` or `invoice:<uuid>`) with its split and its history (charge, transfer, refunds, disputes). |

## Templates and moderation

| Method | Route | What it does |
|---|---|---|
| GET | `/admin/notifications/templates/keys` · `catalog` · `/admin/notifications/templates?key=` | Known keys · catalog with variables · the tenant's overrides. |
| PUT · DELETE | `/admin/notifications/templates/:key` | Override per `(channel, locale)` · deletion (without query params it deletes all of the key's). |
| GET · POST | `/admin/users/:userId/restrictions` | Sanction history · sanctions (`{ scopes[], reason, expiresAt? }` — the user can still sign in and read, not contribute). |
| POST | `/admin/users/:userId/restrictions/:id/lift` | Lifts the sanction (stamps `liftedAt`, does not delete). |
| GET | `/admin/users/:userId/dossier` | Full record (identity, purchases, training, activity, sanctions). **Every query is audited.** |
| GET | `/admin/restrictions/scopes` · `active?userIds=csv` | Sanctionable areas · active sanctions in bulk (max 200). |

The sanctionable areas (`scopes`) are `community`, `messaging`, `uploads`, `ai` and `all` (wildcard: it also covers what is added later). A sanction only cuts **writes** in its area; the person's other requests go through, and the cut ones answer `403 user_restricted` with the reason and the end date. It also applies to the community's external API (`/community-api`): a sanctioned administrator's key does not publish either.

| GET · POST · PATCH · DELETE | `/admin/fundae/groups/:groupId/participants[/:id]` | Named participants (+ `bulk-enroll` from the action's course). Soft-delete → `REMOVED`, Fundae traceability. |
| GET · POST · DELETE | `/admin/fundae/groups/:id/inspectors[/:userId]` | The group's **follow-up accesses**: list (includes revoked ones: who could look is part of the traceability) · grants an account (`{ userId, expiresAt?, notas? }`; it enrolls it in the action's course with source `INSPECTION`, which does not appear in named lists, the XML or the CSVs) · withdraws (marks the row and cancels that enrollment). |

What the account that was granted access (role `inspector`, read-only) or an administrator sees:

| Method | Route | Auth | What it does |
|---|---|---|---|
| GET | `/fundae/inspection/groups` | Bearer | Groups this account can follow right now (live, unexpired grant). |
